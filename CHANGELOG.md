## [0.1.0]

### Added

- Explanations for shell codes 0, 1, 2, 124, 126, 127, 130 and 255.
- 128+N signal codes with Linux and macOS numbering, and `--os` to pick one.
- BSD sysexits codes 64-78.
- `--context` for docker, k8s, curl (1-99), git, npm and ssh.
- `--json` and `--list`.
- Shell hook for bash, zsh and fish via `whyexit init`.
- Releases with GoReleaser, a Homebrew tap and an install script.
